# ADR-0004: 맵과 스테이지를 정적 JSON 카탈로그로 관리

- 상태: 승인
- 날짜: 2026-08-19

## 배경

현행 구현은 맵과 스테이지를 배포 폴더의 JSON 파일에서 읽습니다. 이 데이터는 플레이어 상태와 달리 콘텐츠 버전의 일부이며 서버 실행 중 변경할 필요가 확인되지 않았습니다.

## 결정

- 맵과 스테이지는 각각 `GameData/Catalogs/Maps`, `GameData/Catalogs/Stages`의 JSON 파일로 유지합니다.
- `System.Text.Json`으로 읽습니다.
- 시작 시 전체 파일을 읽고 ID 중복, 스키마, 수치 범위, 좌표와 회전을 검증합니다.
- 검증 실패 시 서버 시작을 실패시킵니다.
- 성공한 카탈로그는 불변 읽기 전용 객체로 메모리에 보관합니다.

## 결과

- 콘텐츠 변경이 Git diff와 배포 버전에 포함됩니다.
- 런타임 조회에 DB round trip이 없습니다.
- 운영 중 콘텐츠 수정은 재배포가 필요합니다.
- DB의 방과 실행 기록이 참조하는 ID가 새 카탈로그에서 제거되지 않도록 호환성 검사가 필요합니다.

## 재검토 조건

- 운영 중 콘텐츠 편집이 필요함
- 비개발 운영자가 관리 UI로 콘텐츠를 배포해야 함
- 카탈로그 크기가 시작 시간이나 메모리 목표를 초과함
