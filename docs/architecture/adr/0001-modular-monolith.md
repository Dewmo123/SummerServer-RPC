# ADR-0001: 단일 프로덕션 프로젝트의 모듈형 모노리스

- 상태: 승인
- 날짜: 2026-08-19

## 배경

현행 저장소는 로그인 서버, 게임 서버, 공용 영속성 프로젝트로 분리되어 있습니다. 사용자 요구사항은 서버 프로젝트를 분리하지 않고 모노리스 방식으로 구현하는 것입니다. 현재 규모에서 프로젝트 간 모델 소유권과 마이그레이션 책임이 분산되어 구조 복잡성이 기능 수보다 큽니다.

## 결정

- `src/SummerProject.Server` 하나의 프로덕션 `.csproj`를 사용합니다.
- 인증과 게임 기능을 하나의 프로세스와 배포 단위로 통합합니다.
- 기능 경계는 `Features` 하위 폴더와 namespace로 유지합니다.
- 테스트는 배포 대상이 아니므로 별도 테스트 프로젝트를 허용합니다.

## 결과

장점:

- 설정, 인증, 로깅, DB 마이그레이션, 배포가 한 곳으로 통합됩니다.
- 기능 간 트랜잭션을 프로세스 내부에서 명시적으로 구성할 수 있습니다.
- AI가 단일 문서·프로젝트 문맥에서 변경을 추적하기 쉽습니다.

비용:

- 빌드와 배포를 기능별로 독립 수행할 수 없습니다.
- 폴더 경계를 지키지 않으면 큰 결합된 코드베이스가 될 수 있습니다.
- 향후 규모가 커질 때 모듈 분리가 추가로 필요할 수 있습니다.

## 재검토 조건

- 기능별 독립 배포 요구가 생김
- 서로 다른 확장 특성 또는 장애 격리가 필요함
- 팀 규모 증가로 단일 프로젝트 빌드·소유권이 병목이 됨
